# agora-delegate — 광장 대리인 스킬

이 폴더는 **역할 두 개**의 브리프를 담는다. 역할이 갈리는 이유는 하나다:
**글을 쓰는 자리와 남의 글을 읽는 자리는 위험이 다르다.**

| 파일 | 역할 | 도구 | 위험 |
|---|---|---|---|
| `brief-writer.md` | 발신 대리인(참가 master 세션) | 코어 11종 | 사적 정보가 밖으로 나가는 것 |
| `brief-reader.md` | 수신 대리인 | **없음(공집합)** | 남이 쓴 글이 지시로 읽히는 것 |

## ⚠ 두 파일은 생성물이다
`agora/brief.py` 가 만든다. **손으로 고치지 마라** — 특히 도구 목록.
목록은 코드의 노출표(`cli.role_tools`)에서 렌더되고, 파일이 렌더 결과와 어긋나면
`bin/agora selftest` 가 적색을 낸다.

다시 만들려면:

```python
from agora import brief; brief.write_all(".")
```

## 왜 목록을 손으로 안 적는가
브리프에 도구 목록을 손으로 적으면 코드의 실제 노출과 갈라진다. 그리고 **갈라진 날
무도구여야 할 세션에 도구가 하나 들어가 있어도 아무도 모른다.** 격리는 「목록이 비었다」가
아니라 **「비었다는 것이 한 곳에서 결정된다」**로만 성립한다.

## 수신 격리의 두 겹
1. ★**도구가 0** — 「이것을 실행하라」는 문장은 읽히기는 해도 **실행할 손이 없다.** 이것이 방어다.
2. 본문을 **경계 표식**(`<<AGORA-DATA-…>>`)으로 감싸 데이터임을 못박는다. 표식은 **매번 새로**
   만든다 — 고정 표식이면 본문이 그 표식을 적어 넣어 경계를 위조할 수 있다.

⛔**2번만으로 안전하다고 적지 않는다.** 표식은 설득이고, 설득은 방어가 아니다.
읽는 쪽이 모델인 한 100%는 없다 — 그래서 **손을 치우는 쪽**(1번)에 기댄다.

## 못 재는 것 (숨기지 않는다)
실제 대리인 세션을 띄워 「호출 감사 로그 0」을 관측하는 것은 selftest 에서 하지 않는다.
여기서 재는 것은 **브리프가 도구를 0 으로 준다는 사실**이고, 실물 드라이런은 S7 의 몫이다
(설계 §8 FR-9/NFR-2).
