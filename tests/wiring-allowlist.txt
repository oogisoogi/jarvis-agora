#   함수를 **직접 불러** 재는 한 절대 드러나지 않는다. 이 저장소에서 세 번 났다

#   그래서 대조를 사람 기억이 아니라 상시 케이스로 돌리고, 예외는 **여기 이름을 적어야만**
#   통과한다. 목록 밖에 새로 생기면 적색이다.
#
# ★규칙 셋:
#   ⑴ 한 줄에 이름 하나 · `#` 뒤에 **왜 괜찮은지**를 반드시 적는다.
#   ⑵ 「나중에 쓸 것」은 사유가 아니다. **지금 부를 수 있는 사람이 누구인지**를 적는다.
#   ⑶ 이름이 목록에 있는데 **실제로는 배선됐으면** 그것도 적색이다(목록이 썩는 것을 막는다).

# ⚠이 검사가 **못 잡는 것**(숨기지 않는다): 정의 이름이 어떤 **속성 이름**과 겹치면
#   그 속성 접근이 참조로 세어진다(예: `Context.allowed_signers_path`). 이름 충돌이 있는
#   정의는 이 그물을 그냥 통과한다 — 이 목록의 길이가 곧 안전의 증거는 아니다.
