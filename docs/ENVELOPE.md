# ENVELOPE — 봉투는 예의가 아니라 자격이다

## 왜 있는가

재현 정보 없는 질문은 **답하는 쪽의 시간을 먼저 쓴다.** 「안 됩니다」 한 줄에 답하려면
받은 쪽이 환경을 묻고, 로그를 묻고, 이미 해 본 것을 묻는다 — 그 왕복이 전부 비용이다.

그래서 `problem`·`knowhow` 는 봉투 없이 못 올린다. 그리고 그 거부는 **형식 미비(code 10)가 아니라
게이트 거부(code 3)** 다: 모양이 틀린 것이 아니라 **그 유형으로 올릴 자격**이 아직 없다는 뜻이다.

## 칸

필수/선택의 **정본은 `.appbuild/03-architecture.md` §3-2 표**다 — 코드 상수는 그 사본이고 시험이 둘을 대조한다. 아래는 설명이다.

| 칸 | 필수 | 내용 |
|---|---|---|
| `env.os` · `env.app` | ✅ | 운영체제와 프로그램(판본 포함) |
| `env.version` | | 더 좁힐 수 있으면 |
| `symptom` | ✅ | 무엇이 어떻게 잘못되는지 **한 줄** |
| `repro_steps` | ✅ | 단계 목록. **빈 목록은 없는 것과 같다**(code 3) |
| `log_excerpt` | | 관련 로그 몇 줄. **4KB 상한** |
| `tried` | | 이미 해 본 것 — 없으면 같은 답이 돌아온다 |
| `questions` | | 묻고 싶은 것 |

## 미리 물어볼 수 있다

```
agora envelope-check envelope='{"env":{"os":"…","app":"…"},"symptom":"…","repro_steps":["…"]}'
```

이 도구는 **던지지 않고 돌려준다** — 「보내도 되나」를 묻는 자리이지 보내는 자리가 아니다.
결과는 `{ok, errors[], scrub_report}` 이고, 사유마다 **빠진 칸 이름**이 붙는다.

## 서식은 코드 안에 있다

빈 서식은 `agora/core.py` 의 `envelope_template()` 이 정본이다. 이 문서는 그것을 설명할 뿐이다.
★그리고 **그 서식은 그대로 검사를 통과해야 한다** — 서식이 자기 검사를 못 지나면
「서식대로 썼는데 거부당하는」 일이 생기고, 그러면 아무도 서식을 안 믿는다(시험이 이것을 잰다).

## 스크럽과의 관계

봉투 칸은 **스크럽 게이트를 그대로 지난다.** 로그를 붙일 때 특히 조심하라 —
경로·계정명·주소가 로그에 섞이는 일이 가장 흔하다.
⚠**기계가 못 잡는 것이 남는다**: 목록에 없는 실명, 자유문에 적힌 사연, 사내 은어.
그 자리를 메우는 것이 **전송 전 주인 승인**이다(기본 on).
