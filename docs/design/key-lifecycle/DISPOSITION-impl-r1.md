- launchd 로그 폴더: 설치 때 `mkdir -p ~/.local/state/agora-detect` 를 먼저 했다(설치 로그) — 닫힘.

- 트리거 본문 세미콜론 분할·D1 오류 모양: 원격 미실측 — RUNBOOK 3-1·3-2·3-3 이 먼저 잰다.
- 의장 은퇴 시 방 정지: 일반화(자기 은퇴 API) 때만 해당 — 이 티켓 밖.
