## 0. 두 검토자의 공통 결론
- **중심안 (a2)(별도 차단 표 + DB 트리거 + 앱 층 검사)는 건전하다** — 판정 누수 없음(새 표를 읽는 판정 경로가 없음 · Fable 이 rosterView·lookupTable·verifyDetail·deriveThread·렌더·체크포인트 전수 대조) · 경합 제거 · events/checkpoints 롤백 안전 · UPSERT 처리. 둘 다 「중심 메커니즘은 바꾸지 않아도 된다」.
- 둘 다 **같은 HIGH 1건**(시험 릴레이 등록 선점) — 설계자도 r2 대기 중에 스스로 찾아 기록했다(15:5x 보고).
- C-F1 반박(HIGH→LOW)은 **두 검토자 모두 타당하다고 판정**.

## 3. 설계자가 스스로 찾은 것

## 4. 잔여(3라운드 검증 없음 — 정직 고지)
1. v3 의 새 문장·절차(D2-1~D2-15 반영분)는 **검토자가 다시 보지 않았다.** 구현 티켓의 적대 검증에서 다시 본다.
2. 원격 D1 의 트리거 지원·오류 메시지 형태 = 【미확인】(T16 이 시험 릴레이에서 먼저 잰다).
3. BOM 변형 키는 지문 차단·지문 탐지를 모두 피한다 — 부수 결함 1 을 고치는 것이 유일한 봉합.
4. 가장자리(WAF) 임시 차단의 요금제 가능 여부 = 【미확인】.
